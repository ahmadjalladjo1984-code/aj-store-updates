# AJ Store Updates

هذا المستودع عام ومخصص لملف تعريف التحديثات وملفات APK الرسمية لتطبيق AJ Store.
يبقى كود التطبيق في المستودع الخاص.

## ملف التحديث

يقرأ التطبيق الملف التالي عند بدء التشغيل:

`latest.json`

- `enabled`: تفعيل أو إيقاف فحص التحديثات.
- `versionName`: رقم الإصدار المعروض للمستخدم.
- `versionCode`: رقم بناء Android، ويجب أن يكون أكبر من النسخة المثبتة.
- `apkUrl`: رابط ملف APK ضمن GitHub Release في هذا المستودع.
- `releaseNotes`: وصف التحديث.

## نشر إصدار جديد

1. أنشئ GitHub Release في هذا المستودع، وأرفق ملف APK باسم `aj-store.apk`.
2. استخدم رابط تنزيل مباشر بالشكل:
   `https://github.com/ahmadjalladjo1984-code/aj-store-updates/releases/download/TAG/aj-store.apk`
3. حدّث `latest.json` بعد التأكد من أن ملف APK متاح.
4. ارفع `versionCode` إلى رقم أعلى من كل إصدار سابق.

## مهم جداً: توقيع Android

يجب توقيع كل إصدار بالمفتاح نفسه تماماً. لا تنشر APK موقعاً بمفتاح Debug متغير.
لا ترفع ملف keystore أو كلمات المرور إلى هذا المستودع العام أو إلى Git.
يجب إعداد أسرار توقيع محمية في إعدادات GitHub Actions قبل بناء إصدار إنتاجي.

لا يطلب التطبيق التثبيت الصامت؛ Android يعرض شاشة التثبيت وموافقة المستخدم، وقد يطلب السماح بتثبيت التطبيقات من هذا المصدر.
